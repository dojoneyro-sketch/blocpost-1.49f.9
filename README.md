# BLOCPOST 1.49.f9

Static landing page for BLOCPOST version 1.49.f9.

## GitHub Pages

The site files are in the repository root. In repository Settings → Pages, select **GitHub Actions** as the publishing source once. The workflow in `.github/workflows/pages.yml` then publishes the page on every push to `main`.

The game archive is not included yet; add an authorized archive separately if you want a working download.
